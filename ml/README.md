# ML Module

This directory will contain machine learning models for:

- **Crop arrival prediction** — Forecast daily/weekly farmer arrivals at each centre
- **Optimal slot allocation** — Dynamic slot sizing based on predicted demand
- **Demand forecasting** — Predict crop volumes by type, season, and region
- **Wait time estimation** — Predict queue wait times based on historical throughput

> **Status**: Not implemented yet. Placeholder for future development.
>
> The database schema is designed to collect the training data needed for these models
> (booking patterns, queue throughput, procurement volumes, seasonal trends).
